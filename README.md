# RoadSense AI 🛣️🤖

**Интеллектуальная система предиктивного мониторинга и анализа дорожной инфраструктуры.**

Проект разработан в рамках хакатона по направлению **AI for Government**. RoadSense AI превращает процесс инспекции дорог из реактивного (исправление жалоб) в предиктивный (предотвращение разрушений).

---


## 📌 Проблема
Традиционные методы мониторинга дорог страдают от:
* **Субъективности:** Оценка качества покрытия зависит от человеческого фактора.
* **Высокой стоимости:** Ручной объезд дорог требует огромных ресурсов.
* **Запоздалой реакции:** Ремонт начинается тогда, когда трещина уже превратилась в глубокую яму, что увеличивает расходы бюджета в 10 раз.

## 💡 Решение
**RoadSense AI** — это программный комплекс, который анализирует видеопоток (например, с камер общественного транспорта или патрульных машин) и в реальном времени формирует цифровой двойник состояния дорог.

### Ключевые функции:
1.  **Автоматическая детекция:** Распознавание ям, трещин и износа разметки с использованием компьютерного зрения.
2.  **Интеллектуальная приоритизация:** Ранжирование заявок на ремонт на основе тяжести дефекта и социальной значимости участка (трафик, близость к школам/больницам).
3.  **Защита от спама:** AI-валидация входящих заявок от граждан для отсеивания ложных сообщений.

---

## 🧠 Роль AI и Технологии (AI/ML)

В проекте реализован комплексный подход к анализу данных:
* **Object Detection (YOLOv8/v11):** Определение типов дефектов на видео/фото.
* **Scoring Engine (Custom Logic):** Алгоритм приоритизации, рассчитывающий индекс критичности (от 0 до 100).
* **Explainable AI (XAI):** Система не просто выдает результат, а генерирует текстовое обоснование принятого решения для эксперта.

> **Важно:** AI в нашей системе выступает как **Decision Support System (DSS)**. Окончательное утверждение плана работ остается за инженером дорожной службы, что соответствует принципам ответственного ИИ.

### Пример объяснимости (Explainability):
> *"Участок ID-402: Приоритет **Высокий (82/100)**. Обоснование: Обнаружена сетка трещин площадью >1 кв.м на магистральной улице. Прогноз: полное разрушение полотна через 2 недели при текущем трафике."*

## 🛠 Технологический стек
* **Backend:** Python, FastAPI (высокая производительность и асинхронность).
* **ML:** PyTorch / Ultralytics (YOLO), OpenCV.
* **Frontend/Dashboard:** Streamlit + Folium (интерактивные карты).
* **Data:** JSON/PostgreSQL для хранения метаданных и координат.

---

## 🏗 Архитектура решения
1.  **Data Ingestion:** Сбор видеоданных с регистраторов.
2.  **Processing Layer:** Детекция дефектов и привязка к GPS-координатам.
3.  **Analytics Layer:** Оценка критичности и генерация объяснений.
4.  **Presentation Layer:** Веб-дашборд с тепловой картой дефектов для госслужащих.

### 🚀 Как запустить

1. Клонируйте репозиторий:
   git clone https://github.com/your-username/roadsense-ai.git
   cd roadsense-ai

2. Создайте и активируйте виртуальное окружение:
   python -m venv .venv
   source .venv/bin/activate  # Для Linux/Mac
   .venv\Scripts\activate     # Для Windows

3. Установите зависимости:
   pip install -r requirements.txt

4. Запустите дашборд:
   streamlit run src/dashboard.py
