🛣️ RoadSense AI: Интеллектуальный мониторинг дорог АлматыRoadSense AI — это комплексная экосистема на базе компьютерного зрения для автоматизированного обнаружения, анализа и приоритизации дорожных дефектов. Проект разработан специально для цифровизации работы городских служб и акимата г. Алматы.Миссия проекта: Перейти от реактивного латания дыр по жалобам к предиктивному управлению городом на основе данных.🌟 Ключевые возможности🤖 Гражданский мониторинг (Telegram Bot): Сбор данных от жителей города. Интегрированный ИИ-фильтр отсеивает спам и нерелевантные изображения (селфи, животные) еще до попадания в базу.🧠 Explainable AI (XAI): Система не просто находит дефект, а объясняет его критичность. Приоритизация строится на анализе типа дороги, трафика и близости к школам/больницам.🗺️ Тепловые карты (Heatmaps): Визуализация плотности дефектов для стратегического планирования ремонта целых кварталов, а не точечных латок.⚖️ Соответствие стандартам: Классификация дефектов согласно СТ РК 1218-2003 и ГОСТ 32883-2014.📑 Автоматизация «под ключ»: Мгновенная генерация PDF-нарядов на ремонт с фото-подтверждением и точными GPS-координатами.🛠 Технологический стекМодульТехнологияЯдро ИИYOLOv8 (Fine-tuned), OpenCVBackendFastAPI (Python), асинхронная архитектураИнтерфейсStreamlit + Folium (Interactive Maps)База данныхSQLite3 (Единый реестр дефектов)Сбор данныхTelegram Bot API (pyTelegramBotAPI)АналитикаScikit-learn (Алгоритмы ранжирования)📐 Математическая модель приоритизации (XAI)Для оценки критичности дефекта используется многофакторная модель. Приоритет ($P$) рассчитывается по формуле:$$P = (S \cdot w_1) + (T \cdot w_2) + (L \cdot w_3)$$Где:$S$: Площадь дефекта (обнаруженная YOLOv8).$T$: Индекс трафика (категория дороги: Магистраль > Местная).$L$: Социальная значимость (близость к школам, больницам, детсадам).$w_{1,2,3}$: Весовые коэффициенты, настроенные согласно нормативам акимата.🚀 Инструкция по запуску1. Подготовка системыУбедитесь, что у вас установлен Python 3.9 или выше.Bash# Клонирование репозитория
git clone https://github.com/ваш-логин/roadsense-ai.git
cd roadsense-ai

# Создание виртуального окружения
python -m venv .venv

# Активация venv
# Для Windows:
.venv\Scripts\activate
# Для Linux/macOS:
source .venv/bin/activate

# Установка всех зависимостей
pip install -r requirements.txt
2. Запуск проектаСистема состоит из двух независимых модулей, которые должны работать одновременно.Запуск Дашборда управления (Admin Panel):Bashstreamlit run src/dashboard.py
Запуск Telegram-бота (Сбор данных):Bashpython src/bot.py
📂 Структура проектаsrc/ — Исходный код (логика детекции, дашборд, бот).data/ — База данных SQLite и медиа-активы.models/ — Обученные веса YOLOv8 (best.pt).assets/ — Скриншоты интерфейса и архитектурные схемы.requirements.txt — Список всех необходимых библиотек.⚠️ Ограничения решенияПогода: Снижение точности детекции при снежном покрове или сильном тумане.Освещенность: В ночное время на неосвещенных участках требуется дополнительная обработка видеопотока.Геолокация: Точность GPS зависит от мобильного устройства пользователя (погрешность до 5-10 метров).🛣️ Дальнейшее развитие (Roadmap)Интеграция с камерами «Сергек»: Автоматический мониторинг основных магистралей города в режиме 24/7.Анализ разметки и знаков: Расширение модели ИИ для контроля всей дорожной инфраструктуры.Предиктивный износ: Использование Big Data для прогнозирования появления новых ям на основе истории ремонта и погоды.👥 Команда проекта (РФМШ Алматы)[Орынтай Марлен] — Lead Developer / Backend / AI Architect.[Даулетов Амиржан] — AI Engineer / Frontend / UX Designer.📄 ЛицензияПроект разработан в рамках финального этапа хакатона.
